# Requisitos Existentes

Esta base fictícia representa requisitos já aprovados pelo grupo. Ela será usada para comparação contra novos requisitos extraídos das transcrições.

## REQ-EXIST-001: Cancelamento de pedidos pagos

Tipo: Funcional

Descrição: O sistema não deve permitir o cancelamento de pedidos pagos após a confirmação do pagamento.

Origem: especificação fictícia de checkout v1.

## REQ-EXIST-002: Revisão humana de respostas

Tipo: Funcional

Descrição: Toda resposta gerada automaticamente para clientes deve ser revisada por um atendente antes do envio.

Origem: especificação fictícia de suporte v1.

## REQ-EXIST-003: Registro de decisão financeira

Tipo: Funcional

Descrição: O sistema deve registrar usuário, data, hora e justificativa em decisões de aprovação financeira.

Origem: especificação fictícia de aprovações v1.
