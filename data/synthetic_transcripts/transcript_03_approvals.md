# Transcrição Sintética 03: Aprovações

Participantes fictícios: Gestor, Analista Financeiro e Desenvolvedor.

Gestor: Alguns pedidos precisam passar por aprovação antes da compra.

- [RF] O sistema deve bloquear pedidos acima do limite permitido até que sejam aprovados.
- [RF] O sistema deve notificar o gestor quando houver um pedido aguardando aprovação.
- [RNF] A notificação deve ser enviada de forma eficiente.

Analista Financeiro: Ainda precisamos definir quem aprova quando o gestor responsável está ausente.

- [RF] O sistema deve registrar a decisão de aprovação ou reprovação de cada pedido.
