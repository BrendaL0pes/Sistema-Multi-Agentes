# Transcrição Sintética 02: Suporte

Participantes fictícios: Suporte, Product Owner e QA.

Suporte: Hoje recebemos muitas dúvidas repetidas e precisamos registrar o motivo do contato.

- [RF] O sistema deve permitir que o atendente registre uma categoria para cada chamado de suporte.
- [RF] O sistema deve sugerir uma resposta inicial com base na categoria do chamado.
- [RNF] A interface de registro de chamado deve ser simples para novos atendentes.

QA: Não ficou claro se a sugestão automática pode ser enviada ao cliente sem revisão humana.

- [RF] O sistema deve permitir que o atendente edite a resposta sugerida antes do envio.
