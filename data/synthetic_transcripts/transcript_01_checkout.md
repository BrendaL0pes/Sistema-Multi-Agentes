# Transcrição Sintética 01: Checkout

Participantes fictícios: Product Owner, Atendimento e Desenvolvedor.

Product Owner: O cliente abandona muito carrinho quando o pagamento demora.

- [RF] O sistema deve permitir que o usuário finalize um pedido usando cartão de crédito.
- [RNF] A confirmação de pagamento deve ser rápida para o usuário final.
- [RF] O usuário deve poder cancelar um pedido pago enquanto ele ainda não tiver sido enviado.

Atendimento: Quando o cancelamento acontece, o cliente precisa receber uma mensagem clara informando o status do pedido.

- [RF] O sistema deve exibir o status atualizado do pedido após uma solicitação de cancelamento.
